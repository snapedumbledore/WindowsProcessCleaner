# 进程内存扫描与清理工具

用 Python 编写的命令行工具：扫描当前所有进程的内存占用，按内存大小排序展示，
并显示每个进程所属的软件（读取 exe 文件版本信息中的产品名/公司名），
在交互终端中于表格右侧绘制内存占比饼图（Top8 + 其他，占物理内存百分比），
支持选择性地结束（清理）占用内存的进程。

## 快速开始

```bash
# 方式一：双击 run.bat 直接启动
# 方式二：命令行启动
py process_cleaner.py            # 交互式
py process_cleaner.py --top 50   # 每次显示前 50 个进程
py process_cleaner.py --list-only  # 只打印列表，不进入交互
```

依赖：`pip install psutil`（当前环境已装 psutil 7.2.1）

## 交互操作

| 输入 | 作用 |
| --- | --- |
| `12,15,18` | 结束列表中第 12、15、18 个进程 |
| `p:1234` | 按 PID 结束进程 1234 |
| `chrome` / `微软` | 结束名称或所属软件匹配的进程（如 chrome、微软） |
| `f:关键词` | 按关键词过滤列表后重新显示（同样匹配进程名和所属软件） |
| `r` | 重新扫描 |
| `q` | 退出 |

选择进程后输入 `y` 确认结束；若目标含软保护进程，需输入 `FORCE-KILL` 才会结束。

## 横向柱状图

表格下方会绘制一张**纯 ASCII 横向柱状图**：显示内存占用前 30 的进程，
柱长按占比线性映射（最长柱代表占比最高的进程），百分比口径为 进程工作集 ÷ 物理内存总量，
标题行同时给出已用内存合计。柱状图随 `f:` 过滤和 `r` 刷新同步更新。

## 安全保护机制

| 级别 | 含义 | 处理方式 |
| --- | --- | --- |
| 硬保护 | 系统关键进程（csrss、winlogon、lsass、svchost、dwm、Defender、输入法等），结束会导致蓝屏/注销/功能失效 | 直接拒绝，无法结束 |
| 软保护 | 资源管理器、控制台宿主等，结束影响体验但可恢复 | 默认拒绝，输入 FORCE-KILL 可强制 |
| 普通 | 其余用户进程 | 确认后结束（先优雅结束，超时才强杀） |

另外：本程序自身及其所在控制台进程自动受保护，不会被误杀。

## 常见问题

- **提示缺少 psutil**：运行 `pip install psutil` 后重试；若用 `python` 启动报错，
  请改用 `py process_cleaner.py`（py 启动器默认版本已装好依赖）。
- **提示权限不足**：部分系统进程需要管理员权限，右键"以管理员身份运行"命令提示符后再执行。
- **看不到某些进程**：非管理员运行时，系统级进程可能被拒绝访问而不显示；管理员运行可看到更多。
- **结束的进程又出现了**：部分软件（服务、守护进程、自动重启类）被结束会自动重启，
  这是正常现象，可配合关闭其开机自启来根治。
